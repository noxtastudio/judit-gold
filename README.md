# Judit Gold — website

One-page site for **Judit Gold Ajándékbolt és Piercingszalon**, Kiskunfélegyháza (Holló Béla u. 1.).
Static HTML/CSS, no build step. Hungarian, tegező. Built by Noxta Studio.

- `index.html`, `assets/style.css`, `assets/img/*.webp` (cropped from her Facebook photos)
- `_fb-photos/` = original downloads, kept out of git
- Wellness piercings are worded without health promises (+ disclaimer) on purpose — Hungarian consumer-protection (GVH) risk.
